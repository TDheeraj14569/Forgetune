### 2.2 Analysis of Speedups
- **Small Batch & Edge Inference Dominance:** At batch sizes $B \in [1, 16]$, ForgeTune substantially outperforms PyTorch CPU eager execution because PyTorch incurs framework dispatch overhead of 30–50 μs per operator call. ForgeTune compiles the entire graph into a single compiled C++ shared library with fused operator loops, delivering genuine E2E speedups up to **5.08x**.
- **Fusion & Codegen Efficacy:** Fused kernels eliminate intermediate write/read cycles to memory, delivering genuine native kernel speedups up to **1.10x** over unoptimized baseline C++ code.
- **Large CNN Multi-Threading Boundary:** At Model C batch 64, PyTorch leverages multi-threaded Intel oneDNN GEMM across all CPU cores, whereas ForgeTune executes a portable single-threaded kernel loop (0.29x E2E). This is an expected architectural characteristic documented transparently.
